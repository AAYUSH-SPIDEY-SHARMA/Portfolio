# Aayush Sharma - Portfolio

A modern, responsive developer portfolio built with React and Tailwind CSS, showcasing projects, open-source contributions, competitive programming achievements, and technical writing.

![React](https://img.shields.io/badge/React-18-61DAFB?logo=react)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.4-38B2AC?logo=tailwind-css)
![Vite](https://img.shields.io/badge/Vite-5.4-646CFF?logo=vite)

## ✨ Features

- **Responsive Design** - Fully optimized for all screen sizes
- **Modern UI** - Clean, professional aesthetic with subtle animations
- **Sticker System** - Anime & Spider-Man themed decorative elements
- **Sections**:
  - Hero with social links
  - Open Source Contributions
  - Competitive Programming Achievements
  - Engineering Projects
  - Technical Writing
  - Footer with Easter Egg

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📁 Project Structure

```
src/
├── assets/          # Images, icons, stickers
├── components/      # Reusable components (Navbar, Hero, Footer)
├── sections/        # Page sections (Projects, OpenSource, etc.)
├── data/            # Content data (projects, links, achievements)
├── styles/          # Custom CSS (stickers.css)
└── App.jsx          # Main app component
```

## 🛠️ Tech Stack

- **Framework**: React 18
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Deployment**: Ready for Vercel/Netlify
